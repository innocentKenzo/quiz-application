# Quiz Application

## Project Description

The Quiz Application is a web-based application that allows students to answer multiple-choice questions and receive their quiz results.

## Main Features

- Display quiz questions and multiple-choice answers.
- Allow students to move between questions.
- Calculate the student's score.
- Display the final score and percentage.
- Allow the student to restart the quiz.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` using Live Server.
3. The Quiz Application will open in the web browser.
